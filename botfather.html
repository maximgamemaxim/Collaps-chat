🐍 Как запустить бота на Python

Скачай файл collaps_bot.py, вставь свой токен и запусти: python3 mybot.py. Библиотека без зависимостей (только Python 3).

from collaps_bot import CollapsBot

bot = CollapsBot("ВСТАВЬ_ТОКЕН")

@bot.command("start")
def start(u):
    u.reply("Привет! Я бот на Python 🐍")

@bot.command("help")
def help_cmd(u):
    u.reply("Команды: /start /help")

@bot.message
def echo(u):
    u.reply("Вы написали: " + u.text)

bot.run()
